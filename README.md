
# DevFolio - Personal Developer Portfolio

## About

A responsive personal developer portfolio created using
HTML5 and CSS3.

This project demonstrates semantic HTML, CSS variables,
Flexbox, CSS Grid, and responsive media queries.

## Features

- Semantic HTML structure
- Responsive navigation
- Custom colour and typography system
- Flexbox layout
- CSS Grid project cards
- Mobile-friendly design
- Contact links

## Technologies Used

- HTML5
- CSS3
- Git
- GitHub Pages

## Run Locally

1. Clone this repository.
2. Open the project folder.
3. Open index.html in your browser.
